Question 1
Which pillar of the AWS Well-Architected Framework focuses on using computing resources in ways that meet system requirements?

answer
A
Reliability
B
Security
C
Performance Efficiency
Correct Answer:
D
Operational Excellence

Explanation
Performance Efficiency means choosing and using computing resources efficiently to meet workload requirements as demand and technology change. Question 3
A cloud engineer is running an Amazon EC2 instance and wants to store data in an attached resource. Their data is temporary and will not be kept long term. Which resource should they use?

answer
A
Subnet
B
Amazon S3 bucket
C
Instance store
Correct Answer:
D
Amazon Elastic Block Store (Amazon EBS) volume

Explanation
An instance store provides temporary block storage on disks attached to the physical host running an EC2 instance. It suits caches and scratch data that can be recreated: data is lost when the instance stops, hibernates, or terminates. EBS is the better match when persistent attached storage is needed.

Question 4
A cloud architect wants Amazon S3 to monitor object access patterns. Which storage class should they use?

answer
A
Amazon S3 One Zone-IA
B
Amazon S3 Glacier Flexible Retrieval
C
Amazon S3 Intelligent-Tiering
Correct Answer:
D
Amazon S3 Standard-IA

Explanation
S3 Intelligent-Tiering monitors access patterns and automatically moves eligible objects between access tiers to optimize storage costs. It is useful when access patterns are unknown or change over time; the other listed classes do not provide this same automatic access-based tiering.

Question 12

answer
A

B
A site that Amazon CloudFront uses to cache copies of content for faster delivery to users at any location
C
A fully isolated portion of the AWS global infrastructure
Correct Answer:
D
A separate geographical location with multiple locations that are isolated from each other

Explanation
