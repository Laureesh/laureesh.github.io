Question 1
Which sequence correctly matches threat detection, vulnerability scanning, and security investigation?

answer
A
GuardDuty; Inspector; Detective
Correct Answer:
B
Inspector; Detective; GuardDuty
C
GuardDuty; Detective; Inspector
D
Detective; GuardDuty; Inspector

Explanation
GuardDuty detects suspicious activity. Inspector identifies software vulnerabilities and network exposure. Detective helps investigate related activity. The other options swap these roles. Remember: alarm, inspection, investigation.

Question 6
Orders must wait until background workers can process them. Which service best fits?

answer
A
Amazon SQS
Correct Answer:
B
Amazon QuickSight
C
Amazon SNS
D
AWS Step Functions

Explanation
SQS buffers messages in a queue for asynchronous processing. SNS publishes to subscribers. Step Functions orchestrates workflows, and QuickSight presents dashboards. Queue consumers should tolerate retries, especially with standard SQS queues.

Question 7
One order event must notify billing, shipping, and analytics, each through its own subscriber queue. Which service provides the topic fan-out?

answer
A
AWS CloudTrail
B
AWS Step Functions
C
Amazon SNS
Correct Answer:
D
Amazon SQS

Explanation
SNS publishes one message to multiple subscribers, including SQS queues. Each queue then buffers work for its subsystem. SQS alone does not broadcast one queue message to all independent subsystems. Step Functions coordinates workflows; CloudTrail records account activity.
