Question 1
Which sequence correctly matches threat detection, vulnerability scanning, and security investigation?

answer
A
GuardDuty; Inspector; Detective
Correct Answer:
B
Inspector; Detective; GuardDuty
C
GuardDuty; Detective; Inspector
D
Detective; GuardDuty; Inspector

Explanation
Different security tools handle detection, weaknesses, and investigation.
Example: A suspicious login triggers an alert; a vulnerable package needs patching; an analyst investigates the incident.
Memory cue: GuardDuty = alarm; Inspector = weaknesses; Detective = investigation.
**Comparison**: **GuardDuty**: Detects suspicious activity and threats.
**Inspector**: Finds software vulnerabilities and network exposure.
**Detective**: Helps investigate security findings and related activity.
