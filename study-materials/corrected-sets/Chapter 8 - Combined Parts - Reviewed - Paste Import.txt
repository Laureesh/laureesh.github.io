Question 1
Which two components execute instructions and hold the programs and data currently in use?

answer
A
CPU and Hard Drive
B
CPU and Memory
Correct Answer:
C
CPU and Disk Drivers
D
CPU and I/O Devices

Explanation
CPU: Processes instructions and controls how quickly the computer performs tasks.
Memory (RAM): Holds programs and data currently being used.
Together: They help determine how much work the computer can handle and how efficiently it performs.

Explanation
In the traditional memory hierarchy, larger-capacity memory is generally slower to access than smaller, faster memory. However, increasing RAM capacity does not automatically increase access time.

Question 6

answer
A
Context Switching
B
Context Handling
C
Locality of Reference
Correct Answer:
D
Indexing

Explanation
Locality of reference means a computer tends to use the same data or nearby data repeatedly.

Memory hierarchy uses this principle to keep frequently accessed data in faster memory, such as cache.

Question 7

Correct Answer:

Serial or Parallel Allocation

Explanation

Non-contiguous allocation divides a process into smaller parts that can be stored in different locations in RAM.

Question 10

answer
A
Logical Address
Correct Answer:
B
Physical Address
C
Abstract Address
D
None of the Above

Explanation
A running program uses logical addresses to refer to its instructions and data.

If the required data is not in RAM, the operating system can load it from secondary storage. The storage device itself uses storage addresses, not logical memory addresses.

Question 11

answer

Contiguous Allocation

B
Non-Contiguous Allocation

Explanation

Question 12
An array stores its elements consecutively in its address space. Which layout does this illustrate?

answer
A
Contiguous Allocation
Correct Answer:
B
Non-Contiguous Allocation

Explanation
An array stores its elements in consecutive memory locations.

This allows the computer to access any element directly using its index.

This is contiguous layout in the program's address space; paging may place those addresses in non-contiguous physical frames.

Question 14
A process requires 10 KB of contiguous memory, but the available memory consists of three separate 4 KB blocks. What problem does this cause?

answer
A
Internal Fragmentation
B
External Fragmentation
Correct Answer:
C
Critical Fragmentation
D
Asynchronous Fragmentation

Explanation
The computer has 12 KB of free memory in total, but it is split into three separate 4 KB blocks.

The process cannot fit because it needs one continuous 10 KB block. This is external fragmentation.

Question 15

answer
A
True
Correct Answer:
B
False

Explanation
Contiguous allocation can leave small, separated gaps of unused memory.

Even if enough free memory exists overall, a process may not fit into one continuous block.

Question 16
Paging eliminates external fragmentation by allowing processes to occupy non-contiguous memory frames.

answer
A
True
Correct Answer:
B
False

Explanation
Paging divides memory into equal-sized frames, so a process does not need one continuous block.

This prevents external fragmentation, although internal fragmentation can still occur.

Question 17

Explanation
A process smaller than its assigned partition leaves allocated space unused. That is internal fragmentation. This should be distinguished from the separated free holes associated with variable-partition external fragmentation.

Question 18

answer
A
True
Correct Answer:
B
False

Explanation
Variable-size partitions are created based on the memory a process needs.

This reduces wasted space inside partitions, but external fragmentation can still occur.

Question 19
Which contiguous memory allocation algorithm selects the largest available free memory block?

answer
A
First Fit
B
Best Fit
C
Worst Fit
Correct Answer:

Explanation
Worst Fit selects the largest available free memory block for a process.

It leaves the biggest possible remaining free block after allocation.

Question 20
Which variable-size allocation algorithm chooses the smallest suitable free block, potentially leaving a tiny leftover hole?

answer
A
First Fit
B
Best Fit
Correct Answer:
C
Worst Fit

Explanation
Best Fit chooses the smallest available memory block that can hold the process.

This can leave tiny unused gaps that are too small for future processes, causing external fragmentation.

First Fit and Worst Fit can also cause external fragmentation; Best Fit is not uniquely affected.

Question 21
What are the two main techniques used to implement non-contiguous memory allocation?

answer
A
First Fit and Best Fit
B
Paging and Segmentation
Correct Answer:
C
Truncation and Blocking
D
Best Fit and Worst Fit

Explanation
Paging divides a process into equal-sized pages that are placed into memory frames.

Segmentation divides a process into logical sections, such as code, data, and stack.

Both allow a process to be stored in separate memory locations.

Question 22
What is a fixed-size block of main memory called in paging?

answer
A
Page
B
Frame
Correct Answer:
C
Index
D
Chunk

Explanation
A frame is a fixed-size block of main memory (RAM).

A page is a fixed-size block of a process's virtual memory. Pages are loaded into available frames.

Explanation

Question 27
Which data structure provides efficient address translation by mapping process pages to memory frames?

answer
A
Indexed Tables (Page Tables)
Correct Answer:
B
Context Switching
C
Local Reference Indexing

Explanation
A page table maps virtual pages to physical frames and includes status and protection information. The operating system maintains the tables; on typical hardware-managed systems, the MMU performs routine address translation, often using a TLB cache.
