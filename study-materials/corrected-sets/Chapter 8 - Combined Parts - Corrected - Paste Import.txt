Question 1
Which two components execute instructions and hold the programs and data currently in use?

answer
A
CPU and hard drive
B
CPU and main memory
Correct Answer:
C
CPU and disk controller
D
CPU and I/O devices

Explanation
The CPU executes instructions; main memory holds active code and data. Other components also affect overall capability.

Question 2
For an efficient memory system, low access time, low cost per bit, and large ______ are desirable.

answer
A
Context switching
B
Threading
C
Capacity
Correct Answer:
D
None of these

Explanation
Capacity measures how much data memory can hold. Designers balance capacity, latency, and cost.

Question 3
Moving down the memory hierarchy from cache toward RAM and secondary storage, what generally happens to access time?

answer
A
It increases
Correct Answer:
B
It decreases
C
It always stays the same
D
It becomes zero

Explanation
Larger, cheaper hierarchy levels are generally slower. Increasing RAM capacity alone does not necessarily increase access time.

Question 6
Memory hierarchy exploits the principle of ______.

answer
A
Context switching
B
Context handling
C
Locality of reference
Correct Answer:
D
Random allocation

Explanation
Temporal locality means reusing recently accessed data; spatial locality means accessing nearby locations.
